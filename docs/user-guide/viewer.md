# Data Viewer モジュール（汎用データビューア）

Data Viewer は、装置やファイル形式を限定せずに**任意の表形式データ**を読み込んで重ね描きするモジュールです。GPC / Spectrum / DLS のような解析機能はありませんが、「測定装置に対応モジュールがない」「Excel で整理した数値をきれいなグラフにしたい」「2 つの量を左右の軸で重ねたい」といった日常の作図をカバーします。

> 対象: LabPlot v1.4.1（Avalonia 主流版）

ポータルの **Viewer カード**（または `Ctrl+4` / macOS は `Cmd+4`）から開きます。

> （スクリーンショット予定: docs/user-guide/images/viewer/00-startup.png）

---

## 1. データを読み込む 3 つの方法

| 方法 | 操作 | 対応形式 |
| --- | --- | --- |
| ファイルを開く | 「CSV / TSV / xlsx を開く」ボタン or `Ctrl+O` | CSV / TSV / セミコロン / 空白区切りテキスト、xlsx |
| ドラッグ & ドロップ | ファイルをウィンドウへドロップ | 同上（複数ファイル可） |
| クリップボード貼り付け | Excel で表をコピー → `Ctrl+V` | タブ区切りテキスト（Excel のコピーはこの形式） |

- 区切り文字（カンマ / タブ / セミコロン / 空白）は自動判定されます。`0,00833` のようなカンマ小数も読めます
- xlsx で複数シートがある場合は、読み込むシートを選ぶダイアログが出ます（既定は全シート）
- 1 行目が数値でない場合はヘッダ行として列名に使われます。ヘッダがないファイルは `Column 1, 2, ...` という名前になります
- 空セルや数値でないセルは欠損（ギャップ）として扱われ、その点だけ線が途切れます

> （スクリーンショット予定: docs/user-guide/images/viewer/10-data-loaded.png）

## 2. サイドバー構成（データ / 仕上げの 2 タブ）

サイドバーは上部のセグメントで**データ**タブと**仕上げ**タブに切り替えます。どちらのタブでも一番下の「既定値」フッターは常に表示されます。

| タブ | セクション | 役割 |
| --- | --- | --- |
| データ | データファイル | ファイルを開く / 最近開いたファイルから再読み込み |
| データ | テーブル | 読み込み済みファイルの一覧。ドラッグで並べ替え、× で削除（既定は折りたたみ） |
| データ | X 列（選択中テーブル） | 「テーブル」セクションで選択中のテーブルについて、横軸に使う列を切り替え |
| データ | 系列 | 読み込んだ**全ファイル横断**の Y 系列一覧。表示 / 非表示・色・凡例名・右軸・並べ替え・変換をここでまとめて操作 |
| データ | 表示条件 | `.gvjson` への保存 / 読み込み（詳細は「6. 保存と出力」） |
| 仕上げ | 軸範囲 | X / Y 軸の表示範囲 |
| 仕上げ | 軸スケール | log10 表示・右 Y 軸のラベルと範囲（詳細は「4. 軸スケール」） |
| 仕上げ | グラフラベル | タイトル・X / Y 軸ラベルの文言と太字設定 |
| 仕上げ | グラフ書式 | フォント・余白・アスペクト比などのグラフ全体の書式 |

> （スクリーンショット予定: docs/user-guide/images/viewer/20-sidebar-tabs.png）

読み込み直後は「**最初の数値列が X、残りの数値列が Y**」として自動でプロットされます（自動で ON になる Y は先頭 8 列まで）。X 列に割り当てた列は「系列」一覧には出ません（数値列がその 1 本しかないテーブルは例外として残ります）。

## 3. 系列一覧の操作

「系列」セクションのリストは、読み込んだ**すべてのファイルの Y 系列**を横断して 1 本のリストにまとめたものです。行ごとに次を操作できます。

| 操作 | 方法 |
| --- | --- |
| 表示 / 非表示 | 行左のチェックボックス |
| 色・グラフ種別・線幅・マーカー・右軸割り当て・変換 | 行を選択 → 下のスタイルパネルで編集（右軸に割り当て中の行には「右軸」バッジが表示されます） |
| 凡例名の変更 | 行の表示名を**ダブルクリック**、または選択して `F2` → 入力して `Enter`（`Escape` で取り消し） |
| 描画順・凡例順・エクスポート順の変更 | 行左端の**ドラッグハンドル**（点が並んだアイコン）を掴んで上下にドラッグ |

複数の系列を `Ctrl` クリック / `Shift` クリックで選択すると、色・グラフ種別・線幅・マーカー・右軸割り当ての変更が選択中の**全件**に一括反映されます（変換は最後に選択した 1 系列のみが対象です）。一覧の並び順がそのままプロットの描画順・凡例の表示順・データ出力の列順になります。

## 4. 軸スケール（log / 右 Y 軸）

**仕上げ**タブの**軸スケール**セクションで、X 軸・左 Y 軸・右 Y 軸それぞれを log10 表示に切り替えられます。

- log 軸では 0 以下の点は描画されません（欠損扱い）
- 軸範囲の指定は常に**データの単位**で入力します（log 変換後の値ではありません）
- 右 Y 軸のラベルと範囲（Min / Max）もこのセクションで指定できます。空欄なら自動です

## 5. 系列ごとの変換（非破壊）

**系列**セクションの「変換」で、選択中の系列にだけ表示用の変換をかけられます。元データは変更されないので、チェックを外せばいつでも戻ります。

| 変換 | 内容 |
| --- | --- |
| 正規化 (max = 1) | 系列の絶対値最大が 1 になるようスケール |
| Y オフセット | 系列全体を Y 方向に平行移動（重ね描きの見やすさ調整に） |
| 平滑化窓 | 中央移動平均の窓幅。0 / 1 で無効、偶数は奇数に丸め |

適用順は 平滑化 → 正規化 → オフセット です。変換は複数選択時も末尾選択の 1 系列にのみ適用されます。

## 6. 保存と出力

| 操作 | ショートカット | 内容 |
| --- | --- | --- |
| グラフ保存 | `Ctrl+S` | PNG（300 dpi）または SVG |
| データ出力 | `Ctrl+E` | 表示中の系列を CSV / xlsx で出力（変換適用後・データ単位） |
| 表示条件を保存 | `Ctrl+Shift+S` | `.gvjson` ファイルに現在の状態を保存 |
| 表示条件を読み込み | `Ctrl+Shift+O` | `.gvjson` から状態を復元 |

表示条件（`.gvjson`）には、テーブル・X 列マッピング・系列一覧（表示順・スタイル・凡例名・変換）・軸設定・グラフ書式が含まれます。ファイル由来のテーブルは**パス参照**なので元ファイルが必要ですが、クリップボード由来のテーブルは**データごと埋め込まれる**ため、`.gvjson` 単体で復元できます。

> （スクリーンショット予定: docs/user-guide/images/viewer/50-session.png）

## 7. その他の操作

- 系列の色 / 凡例名 / 線幅 / マーカー / 並べ替えは**系列**セクションで編集（詳細は「3. 系列一覧の操作」）
- 凡例はプロット上で直接ドラッグして移動できます
- 読み込み済みテーブルはリスト内のドラッグで並べ替え、× ボタンで削除
- `F1` でショートカット一覧、`Ctrl+R` で軸範囲リセット、`Ctrl+G` でグリッド切替
- 最近開いたファイルはサイドバーの「最近開いた」から再読み込みできます（ポータルの最近開いたファイル一覧にも出ます）
