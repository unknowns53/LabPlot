# LabPlot.DLS

Malvern Zetasizer の DLS（動的光散乱）測定ブックを読み込んで、粒径分布と自己相関関数を可視化し、キュムラント解析で Z-average / PdI / 流体力学半径を算出する Windows 用デスクトップアプリです。GPC / Spectrum と同じ操作感を踏襲しつつ、`LabPlot.Core` / `LabPlot.Core.Wpf` の共通基盤を共有しています。

主な機能:

- Zetasizer の xlsx エクスポートを ClosedXML 経由で読み込み（1 シート＝1 測定、列ヘッダから Number / Intensity / Volume / 相関関数を自動分類）
- 重ね描き、線色（プリセット + Custom HSV / hex）・線幅・凡例名の個別設定、ListBox 上のドラッグで並び替え
- 分布タイプ（Number / Intensity / Volume / 自己相関 g₂−1）と Run（通常 3 回繰り返し）の切替
- キュムラント解析: フィット範囲指定（空欄で自動検出、g₂−1 ≥ 0.1 を保持）、Z-average 径・PdI・第 1 累積量 Γ・R² を表示
- Stokes–Einstein 式で流体力学径を算出（測定条件「温度・濃度・溶媒・屈折率・粘度・波長・散乱角」をサイドバーで補完）
- 軸範囲・タイトル・フォント・グリッド・プロット枠・アスペクト比の調整
- 300 dpi PNG または SVG で書き出し、xlsx / csv で解析結果を出力
- 解析条件（読み込み済みデータ・線スタイル・測定条件・キュムラント解析・軸範囲・グラフ書式）を `.dlsjson` として保存・復元

> Zetasizer の xlsx は温度・粘度・屈折率を確実な形で埋めてくれない（測定者の運用次第）ため、Stokes–Einstein 計算に使うパラメータはサイドバーの「測定条件」で手入力する設計になっています。値が揃うとキュムラント解析カードに流体力学径が表示されます。

---

## 1. インストール

研究室で配布された `LabPlot.DLS.exe`（自己完結型ビルド）を任意のフォルダに置いて、ダブルクリックで起動するだけです。.NET ランタイムの別途インストールは不要です。

---

## 2. データを開く

サイドバー上部「データファイル」セクションの **「Excel を開く」** をクリックして、Zetasizer の xlsx を選択します。

- ワークブック内のシートが 1 つずつデータセットとして読み込まれます。各シートのサンプル名は列ヘッダ（例: `Size (d.nm) - 1-41_2_20 [Steady state]`）から自動抽出されます。
- 同じ xlsx を Excel で開いたままでも読み込めます（`FileShare.ReadWrite | FileShare.Delete` で開いています）。
- 読み込み済みのデータは「読み込み済みデータセット」セクションに一覧表示されます。リスト上のドラッグで並び替え、各行右端の **×** で削除できます。

---

## 3. 分布タイプと Run の切替

サイドバー「表示」セクションから操作します。

- **分布の種類**: `Number (%)` / `Intensity (%)` / `Volume (%)` / `自己相関 g₂−1` を切り替えます。Number / Intensity / Volume は粒径（nm）を X 軸に、g₂−1 は遅延時間（μs）を X 軸に取り、軸ラベルとスケールが自動的に切り替わります。
- **Run**: Zetasizer は通常 3 回繰り返し測定を 1 シート内に記録します。ドロップダウンから個別の Run を選択できます。

---

## 4. 測定条件の補完

サイドバー「測定条件」セクション（選択中のシート単位）に、Stokes–Einstein 計算で使うパラメータを入力します。

- **温度 (°C)**, **濃度 (mg/mL)**, **溶媒**, **屈折率**, **粘度 (mPa·s)**, **波長 (nm)**, **散乱角 (°)** の 7 項目。
- 必須なのは温度・粘度・波長・散乱角の 4 つで、欠けている項目はキュムラント解析カードのステータスメッセージに列挙されます。
- 値はシート単位で記憶され、`.dlsjson` に保存されるので、次回読み込み時に同じ値が復元されます。

---

## 5. キュムラント解析

サイドバー「キュムラント解析」セクションは選択中のシートに対して動作します。

- **フィット範囲 (μs)**: 空欄にすると `g₂−1 ≥ 0.1` を保持する範囲が自動選択されます。任意で min / max を直接入力することも可能。
- **Z-average 径**, **PdI**, **Γ**, **適用範囲**, **R²** が表示されます。Stokes–Einstein 計算に必要な測定条件が揃っていれば Z-average 径として流体力学径が、揃っていなければ Γ から計算可能な値だけが表示され、不足項目はステータスメッセージで案内されます。

理論上は `ln|g₁(τ)| ≈ −Γτ + (μ₂/2)τ² − …` を Siegert 関係 `g₂−1 = β·|g₁|²` 経由で `y = ln(g₂−1)` の 2 次多項式に置き換え、`a₁ = −2Γ`, `a₂ = μ₂` から PdI = μ₂/Γ² を求めています。詳細は `DlsAnalyzer.Core/CumulantAnalyzer.cs` を参照してください。

---

## 6. グラフ調整

サイドバーの「線スタイル」「軸範囲」「グラフラベル」「グラフ書式」の各セクションから、書式を調整します。

- **線スタイル**: 選択中のデータセットの色・凡例名・線幅・マーカーサイズを設定します。色は名前付きプリセットに加え、Custom 選択時は hex 入力 / HSV パレットが利用できます。
- **軸範囲**: マウスでドラッグ・ホイール操作後、TextBox に表示された値を微調整するのが楽です。空欄に戻して **「自動範囲に戻す」** を押すと自動レンジに戻ります。粒径分布では X 軸が log スケールになります。
- **グラフラベル**: タイトル、X 軸、Y 軸ラベルを直接入力します。タイトル・軸ラベルは太字切替、タイトルは表示／非表示の切替もできます。
- **グラフ書式**: フォント、フォントサイズ、グリッド表示、プロット枠（色・幅）、背景色、凡例位置、アスペクト比（16:9 / 4:3 / 3:2 / 1:1 / 自動）を指定できます。

書式設定は **「既定保存」** ボタンで `%APPDATA%\LabPlot.DLS\formatting_config.json` に保存され、次回起動時に復元されます。**「既定に戻す」** で保存済み設定にリセットできます。

---

## 7. 出力

メインエリア右上の 2 つのボタンから書き出します。

- **「PNG / SVG 保存」**: 分布／自己相関グラフを出力します。PNG は 3600×2160 / 300 dpi、SVG はベクターで保存されます。アスペクト比設定が出力サイズに反映されます。
- **「データ出力」**: 分布データ・相関関数・キュムラント解析結果を Excel ブック（`.xlsx`）または CSV で書き出します。

---

## 8. 解析条件を保存・読み込む

サイドバー下部「解析条件」セクションから操作します。

- **「条件を保存」（Ctrl+Shift+S）**: 読み込んでいるデータファイルパス、線スタイル、軸範囲、書式、測定条件、キュムラント解析の設定をまとめて `.dlsjson` に書き出します。
- **「条件を読込」（Ctrl+Shift+O）**: 保存した `.dlsjson` を読み込んで状態を復元します。データファイルの実体は元の場所から再読込されるため、ファイルが移動・削除されているとその項目だけ警告つきでスキップされます。

---

## 9. 環境設定（任意）

サイドバー最下部の「環境設定」セクションから、よく使う既定値を保存できます。

- **既定の分布**: Number / Intensity / Volume / 自己相関 のうち、起動時に最初に開く分布タイプ。
- **既定の Run**: 起動時に選択しておく Run のインデックス。
- **既定の出力フォルダ**: グラフ・データ・解析条件の保存ダイアログでこのフォルダが最初に開かれます。

入力後はサイドバー下部の **「既定保存」** を押すと反映されます。

---

## 詳細仕様メモ

- Zetasizer の列ヘッダは `<DataType> (<unit>) - <SampleName> [<State>]` という構造を仮定しており、`Size (d.nm)` / `Number (Percent)` / `Intensity (Percent)` / `Volume (Percent)` / `Correlation` / `Time` のキーワードで分類します。`DlsAnalyzer.Core/DlsHeader.cs` を参照してください。
- キュムラント解析は遅延時間 μs を基準にしており、Γ は μs⁻¹、μ₂ は μs⁻² で内部計算した上で、UI 表示・Stokes–Einstein 計算用に SI 単位（s⁻¹, m²/s）へ変換しています。
- Stokes–Einstein 式は `D = kT / (6πηR_h)` を `R_h = kT / (6πηD)` に変形して使い、散乱ベクトル `q = (4πn/λ)·sin(θ/2)` から拡散係数 `D = Γ/q²` を計算しています。屈折率・粘度・波長・散乱角のいずれかが欠けると計算をスキップし、UI に不足項目を表示します。
- セッション JSON は UTF-8（BOM 付き）で書き出され、`%APPDATA%\LabPlot.DLS\formatting_config.json` の既定書式とは別のファイルです。

## 開発者向け

ビルドとテスト:

```powershell
dotnet build LabPlot.DLS.slnx
dotnet test DlsAnalyzer.Tests/DlsAnalyzer.Tests.csproj
```

配布用の単一 exe を作成:

```powershell
dotnet publish LabPlot.DLS/LabPlot.DLS.csproj -p:PublishProfile=win-x64
```

成果物は `LabPlot.DLS/bin/Release/net10.0-windows10.0.19041/win-x64/publish/` に出力されます。

プロジェクト構成:

```text
LabPlot.DLS/                 WPF アプリ本体
DlsAnalyzer.Core/            解析ロジック（xlsx リーダ、ヘッダ分類、キュムラント解析、Stokes–Einstein、エクスポート）
DlsAnalyzer.Tests/           xUnit による単体テスト
```

`DlsAnalyzer.Core` は WPF 非依存で、`LabPlot.Core` のセッション・エクスポート抽象（`AnalysisSession` / `IAnalysisExporter` / `IDataReader<T>`）を踏襲しています。WPF 側の共通スタイル・パネル・ダイアログは `LabPlot.Core.Wpf` 経由で取り込んでいます。
