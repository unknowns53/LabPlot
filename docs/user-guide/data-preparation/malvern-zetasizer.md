# Malvern Zetasizer のデータ準備（DLS 用）

Malvern Zetasizer で取得した DLS（動的光散乱）データを LabPlot の [DLS モジュール](../dls.md) で開くためのガイドです。

> 対象モジュール: [DLS](../dls.md)
> 対象装置: Malvern Zetasizer

---

## LabPlot 側が期待するファイル形式

DLS モジュールは Zetasizer 付属ソフトから出力された xlsx エクスポートを ClosedXML 経由で読み込みます。基本的なルールは次のとおりです。

- **1 シート＝1 サンプル**: ワークブック内のシートが 1 つずつデータセットとして読み込まれます。複数のサンプルを 1 ファイルにまとめても構いません。
- **同じ xlsx を Excel で開いたままでも読み込めます**: LabPlot 側は共有読み取りで開くので、Zetasizer ソフトや Excel で開きながら参照できます。

---

## 列ヘッダの推奨形式

Zetasizer の付属ソフトから素直にエクスポートすると、列ヘッダは次の構造になります。

```text
<DataType> (<unit>) - <SampleName> [<State>]
```

例:

```text
Size (d.nm) - 1-41_2_20 [Steady state]
Number (Percent) - 1-41_2_20 [Steady state]
Intensity (Percent) - 1-41_2_20 [Steady state]
Volume (Percent) - 1-41_2_20 [Steady state]
Time (microseconds)
Correlation Coefficient - 1-41_2_20 [Steady state]
```

LabPlot は次のキーワードを見て列を自動分類します。

| キーワード | 用途 |
| --- | --- |
| `Size (d.nm)` | 粒径（X 軸） |
| `Number (Percent)` / `Intensity (Percent)` / `Volume (Percent)` | 各分布の Y 軸 |
| `Time` | 自己相関関数の遅延時間（X 軸） |
| `Correlation` | 自己相関 g₂−1 の Y 軸 |

サンプル名（`SampleName`）と状態（`[State]`）はリスト表示・凡例の生成に使われます。

## Run（繰り返し測定）の扱い

Zetasizer は通常 1 サンプルにつき 3 回の繰り返し測定を 1 シート内に記録します。LabPlot 側ではドロップダウンで Run を切り替えて、それぞれの粒径分布や自己相関関数を見られます。詳細は [DLS モジュールの分布タイプと Run の切替](../dls.md#2-分布タイプと-run-の切替) を参照してください。

## 測定条件メタデータの欠損対策

Zetasizer の xlsx は、測定温度・粘度・屈折率といったメタデータを確実な形では埋めてくれません（測定者の運用次第です）。LabPlot の DLS モジュールは Stokes–Einstein 計算で「温度・粘度・波長・散乱角」の 4 項目を必須としているので、xlsx 側に欠けている場合は **解析ウィンドウの「測定条件」セクションで手入力** する必要があります。

入力した値はシート単位で記憶され、`.dlsjson` セッションファイルに保存されるので、研究室の標準条件をテンプレートとして用意しておくと運用しやすくなります。詳しくは [DLS モジュールの測定条件の補完](../dls.md#3-測定条件の補完) を参照してください。

## よくあるエラー

**列ヘッダが認識されず、データが空になる**

- 列ヘッダが `<DataType> (<unit>) - <SampleName> [<State>]` の形式から外れていないか確認してください。Zetasizer ソフト側で列名を編集したり、Excel で結合セルを使ったりすると認識できなくなります。
- 文字コードが xlsx の標準（UTF-8）から外れていないかも確認してください。

**シート名が衝突して読み込めない**

- 同じワークブック内に同名のシートが含まれているとエラーになります。Zetasizer 側でサンプル名を変えるか、シートをリネームしてからエクスポートしてください。

**Z-average 径が表示されない**

- 「測定条件」セクションで温度・粘度・波長・散乱角が揃っているかを確認してください。欠けている項目はキュムラント解析カードのステータスメッセージに列挙されます。
- 必須項目が揃っていても Γ から計算可能な値だけが表示される場合は、屈折率の入力を確認してください。

そのほかのトラブルは [トラブルシューティング](../troubleshooting.md) を参照してください。
