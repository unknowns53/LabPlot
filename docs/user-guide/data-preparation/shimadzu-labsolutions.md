# Shimadzu LabSolutions のデータ準備（GPC 用）

Shimadzu LabSolutions で取得した GPC 測定データを LabPlot の [GPC モジュール](../gpc.md) で開くためのガイドです。

> 対象モジュール: [GPC](../gpc.md)
> 対象装置: Shimadzu LabSolutions（GPC）

---

## LabPlot 側が期待するファイル形式

GPC モジュールは次のいずれかの形式を読み込めます。

**1. LabSolutions の TXT エクスポート**

LabSolutions の標準的なテキストエクスポート機能で出力されたファイルです。ヘッダ部とデータブロックを含み、`Average Molecular Weight Table` セクションが含まれていれば、Mn / Mw / Đ などの代表ピーク情報も自動で読み込まれます。

参考になる同梱サンプル:

- `samples/20260116_2-000_C-PNIPAM_DMF.txt`
- `samples/20260116_2-058_S-PNIPAM_DMF.txt`

**2. `Time, Signal` 形式の CSV / TSV**

任意のソフトで以下のような 2 列形式に整形したデータも読めます。区切り文字はカンマ（CSV）またはタブ（TSV）です。

```text
Time, Signal
0.000, 0.123
0.005, 0.130
0.010, 0.142
...
```

ヘッダ行の有無は自動判定されます。データの単位は装置側のエクスポート時の単位（通常は分・mV または分・任意単位）がそのまま使われます。

## 較正曲線 JSON の準備

GPC モジュールで分子量分布を表示するには、別途較正曲線 JSON が必要です。1 つの JSON ファイルに複数の溶媒・検出器の係数をまとめて持たせる形式です。同梱サンプル `samples/standard_curve.json` の構造を参考にしてください。

研究室共通の較正曲線 JSON を運用する場合は、[GPC モジュールの環境設定](../gpc.md#6-環境設定任意) で「既定の較正曲線」として登録しておくと、起動時に自動でロードされます。

## よくあるエラー

**「ファイル形式が認識できません」と表示される**

- LabSolutions の TXT を Excel で開いて上書き保存していないか確認してください。Excel が文字コードを CP932（Shift-JIS）に変換すると、行末コードと併せて読み取りに失敗することがあります。
- `Time, Signal` 形式の CSV を作った場合は、区切り文字（カンマ／タブ）と列順を再確認してください。

**Mn / Mw が表示されない**

- LabSolutions の TXT に `Average Molecular Weight Table` が含まれているかを確認してください。エクスポート設定で表を含めない選択をすると LabPlot 側でも数値が出ません。
- 較正曲線 JSON を読み込み、「分子量表示」にチェックを入れているかも確認してください。

**読み込めるが数値の単位がおかしい**

- 装置側でのエクスポート時の単位（分・秒、mV・任意単位 など）と、LabPlot 側で表示している軸ラベルの単位を見比べてください。装置設定で意図せず単位が変わっていることがあります。

そのほかのトラブルは [トラブルシューティング](../troubleshooting.md) を参照してください。
