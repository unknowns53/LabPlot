# トラブルシューティング

LabPlot を使っていてつまずきやすいポイントと、その対処方法をまとめました。それぞれの症状ごとに、まず試してほしい項目を順に並べています。

> 対象: LabPlot v1.4.1（Avalonia 主流版）

---

## 起動できない / 起動直後にクラッシュする

### Windows

- **「WindowsによってPCが保護されました」と表示されて起動できない**: 「詳細情報」をクリックして「実行」を選んでください。配布物が未署名のため SmartScreen が標準でブロックします。
- **ダブルクリックしても何も起きない**: 配布物の zip を解凍したフォルダ内で `LabPlot.Avalonia.exe` を実行しているか確認してください。zip 内のファイルを直接ダブルクリックすると一時フォルダで起動しようとしてエラーになることがあります。
- **起動時に DLL エラーが出る**: 配布物を別のフォルダにコピーする際にファイルの一部だけが選択されている可能性があります。zip からまるごと展開し直してください。

### macOS

- **「"LabPlot.app" は壊れているため開けません」と表示されて起動できない**: ファイルが壊れているわけではなく、ブラウザ経由のダウンロードで付く隔離属性（quarantine）と未署名配布の組み合わせに対する macOS 標準の警告です。ターミナルから隔離属性を外してください。右クリック → 「開く」ではこの警告を回避できません。
  ```bash
  xattr -dr com.apple.quarantine /Applications/LabPlot.app
  ```
  パスは `LabPlot.app` を置いた場所に合わせて読み替えてください。次回以降のインストール・更新は、隔離属性の付かない [ターミナルからのインストール](./installation.md#インストールmacos) を推奨します。

### Linux

- **ダブルクリックで起動しない**: 実行権限が付いているか確認してください。
  ```bash
  chmod +x ~/Apps/LabPlot/LabPlot.Avalonia
  ```
- **GUI が表示されない**: WSL2 環境の場合は WSLg（Windows 11 標準）が有効か確認してください。リモートサーバーの場合は X11 / Wayland のディスプレイ転送設定が必要です。

---

## ファイルが開けない

- **エンコーディング**: JASCO の TXT は Shift-JIS、Zetasizer の xlsx は UTF-8 が標準です。装置から出力したオリジナルファイルをそのまま使ってください。Excel で開いて上書き保存すると文字コードが変わって読み取りに失敗することがあります。
- **区切り文字**: GPC の CSV / TSV はカンマまたはタブが標準です。カスタムの区切り文字（セミコロン・スペースのみ など）には対応していません。
- **ヘッダ欠損**: JASCO の TXT は `DATA TYPE` 行で種別を判定するので、ヘッダ部の改変は避けてください。Zetasizer の xlsx は列ヘッダから種別を判定するので、列名の編集や結合セルの使用は避けてください。
- **装置別の詳細**: 装置ごとの典型的な失敗例は [装置別データ準備](./data-preparation/README.md) の各ページにまとめてあります。

---

## グラフが表示されない / 「graph initialising...」のままになる

- **データ未読み込み**: グラフエリアに「load a file to display data here」と表示されているのは、まだデータが読み込まれていない正常な状態です。「データファイル」セクションからファイルを開いてください。
- **読み込みが進まない**: 巨大なファイル（数十 MB 以上の TXT）を開くと初回描画に数秒かかることがあります。ステータスバーを確認してください。
- **読み込み済みなのに何も描かれない**: データセット一覧で対象のチェックが外れていないか、線色が背景と同じになっていないかを確認してください。
- **データセットを全部削除した後に空のままになる**: × でデータセットを全削除すると、プレースホルダ（「load a file to display data here」）が再表示される設計になっています。これは v1.2.0 の修正で安定しました。表示されない場合はバグの可能性があるので [GitHub Issues](https://github.com/unknowns53/LabPlot/issues) に報告してください。

---

## ファイルのドラッグ＆ドロップが効かない

- **ドロップ先**: ファイルは「読み込み済みデータセット」のリスト領域にドロップしてください。グラフエリアやサイドバー全体ではドロップが効きません。
- **重ね描きの状態**: 「重ね描き (Overlay)」のチェック有無は、ドラッグ＆ドロップ時にも反映されます。チェックを外している状態で複数ファイルをドロップすると、最後の 1 ファイルだけが残るので注意してください。
- **データセット並び替えとの衝突**: リスト内のデータセットをドラッグして並び替えるときと、エクスプローラーから外部ファイルをドロップするときで挙動が異なります。マウスを離す位置がリストの内側 / 外側のどちらに該当しているか確認してください。

---

## フォントが薄い / 読みづらい

- **Windows / macOS**: v1.2.0 でデフォルトフォントウェイトとサブピクセルアンチエイリアスの設定を見直しています。古い v1.1.0（WPF 版）よりも文字がくっきり見えるはずです。それでも薄く見える場合は、ディスプレイの ClearType 設定（Windows）や RGB サブピクセル順序を確認してください。
- **Linux で日本語が豆腐（□□□）になる**: CJK フォントが入っていません。次のコマンドでインストールしてください。
  ```bash
  sudo apt install fonts-noto-cjk
  ```
- **グラフ内の数字や記号が小さすぎる**: 「グラフ書式」セクションで「フォントサイズ」を上げてください。投稿論文向けには 16 pt 以上を推奨します（出荷時デフォルトも 16 pt です）。

---

## 解析条件ファイル（.gpcjson / .specjson / .dlsjson）が読み込めない

- **データファイルが移動・削除されている**: セッションファイルにはデータファイルへの絶対パスが含まれます。元のデータファイルが見つからない場合、その項目だけ警告つきでスキップされます。読み込み後にステータスメッセージを確認してください。
- **別 PC や別ユーザーのファイルを使っている**: パスが違うと再現できません。データファイルとセッションファイルをセットで揃えて、同じディレクトリ構造に展開してください。詳細は [FAQ のセッションファイル可搬性](./faq.md#セッションファイル-gpcjson--specjson--dlsjson-を別-pc-や別ユーザーに渡しても大丈夫ですか) を参照してください。
- **セッションファイル自体が壊れている**: テキストエディタで開いて、UTF-8 BOM 付きの JSON 構造になっているかを確認してください。Excel や非対応エディタで上書き保存すると壊れることがあります。

---

## ログの場所と内容

予期せず終了した場合や、画面に出ないバックグラウンドで例外が起きている可能性がある場合は、`shell-error.log` を確認してください。

| OS | ログパス |
| --- | --- |
| Windows | `%LocalAppData%\LabPlot\Logs\shell-error.log` |
| macOS | `~/Library/Application Support/LabPlot/Logs/shell-error.log` |
| Linux | `~/.local/share/LabPlot/Logs/shell-error.log` |

ログには発生時刻、例外の種類、メッセージ、スタックトレースが追記されていきます。再現性のあるエラーが出ている場合は、その時刻あたりのエントリを抜き出してから報告すると原因究明が早くなります。

---

## それでも解決しない場合

[GitHub Issues](https://github.com/unknowns53/LabPlot/issues) に報告してください。次の情報を含めると再現が早くなります。

```text
## 環境
- OS: （例: Windows 11 23H2 / macOS 14.2 / Ubuntu 22.04 LTS）
- LabPlot のバージョン: （例: v1.4.1、配布 zip の名前で OK）
- 対象モジュール: （GPC / Spectrum / DLS / Viewer）

## 発生した症状
（何を期待していて、実際にどうなったかを 1〜2 文で）

## 再現手順
1. （例: ポータルを起動して GPC カードをクリックした）
2. （例: 「CSV / TXT を開く」で samples/20260116_2-000_C-PNIPAM_DMF.txt を選択した）
3. （例: 「PNG / SVG 保存」を押したらアプリが終了した）

## 添付したい情報
- shell-error.log の該当部分（時刻と例外メッセージ）
- 可能であればスクリーンショット
- 失敗するファイル（差し障りがなければ）
```

研究データの取り扱いに制約がある場合は、ファイル本体は同梱せず、列構造だけを書き写したものを添えても十分です。
