# DLS モジュールの使い方

Malvern Zetasizer の DLS（動的光散乱）測定ブックを読み込んで、粒径分布と自己相関関数を可視化し、キュムラント解析で Z-average / PdI / 流体力学半径を算出するモジュールです。

> 対象: LabPlot v1.2.0（Avalonia 主流版）

---

## このモジュールでできること

- Zetasizer の xlsx エクスポートを読み込み（1 シート＝1 測定、列ヘッダから Number / Intensity / Volume / 相関関数を自動分類）
- 重ね描き、線色（プリセット + Custom HSV / hex）・線幅・凡例名の個別設定
- 分布タイプ（Number / Intensity / Volume / 自己相関 g₂−1）と Run（通常 3 回繰り返し）の切替
- キュムラント解析: フィット範囲指定（空欄で自動検出、g₂−1 ≥ 0.1 を保持）、Z-average 径・PdI・第 1 累積量 Γ・R² を表示
- Stokes–Einstein 式で流体力学径を算出（測定条件「温度・濃度・溶媒・屈折率・粘度・波長・散乱角」をサイドバーで補完）
- 軸範囲・タイトル・フォント・グリッド・プロット枠・アスペクト比の調整
- 300 dpi PNG または SVG で書き出し、xlsx / csv で解析結果を出力
- 解析条件を `.dlsjson` として保存・復元（Ctrl+Shift+S / Ctrl+Shift+O）

---

## 対応装置と事前準備

主な対応装置は **Malvern Zetasizer** です。Zetasizer 付属ソフトから xlsx 形式でエクスポートしたブックをそのまま開けます。1 シート＝1 サンプル、列ヘッダは `Size (d.nm) - <SampleName> [<State>]` のような形式が前提です。

Zetasizer の xlsx は温度・粘度・屈折率を確実な形では埋めてくれない（測定者の運用次第）ため、Stokes–Einstein 計算に使うパラメータはサイドバーの「測定条件」で手入力する設計になっています。値が揃うとキュムラント解析カードに流体力学径が表示されます。

装置側でのエクスポート手順は [Malvern Zetasizer のデータ準備](./data-preparation/malvern-zetasizer.md) を参照してください。

実機データが手元に無くても、配布物の `samples/demo.xlsx` に合成データ（PNIPAM の単峰コイル + 二峰凝集体の 2 シート）が同梱されているので、それで一通りの操作を試せます。詳細は [サンプルデータ一覧](./samples.md#dls-サンプル) を参照してください。

---

## 1. データを開く

サイドバー上部「データファイル」セクションの **「Excel を開く」** をクリックして、Zetasizer の xlsx を選択します。

- ワークブック内のシートが 1 つずつデータセットとして読み込まれます。各シートのサンプル名は列ヘッダ（例: `Size (d.nm) - 1-41_2_20 [Steady state]`）から自動抽出されます。
- 同じ xlsx を Excel で開いたままでも読み込めます（共有読み取りで開いているため）。
- 読み込み済みのデータは「読み込み済みデータセット」セクションに一覧表示されます。リスト上のドラッグで並び替え（ドラッグ中はゴーストが追従）、各行右端の **×** で削除できます。
- ファイルエクスプローラーから直接データセット一覧へドラッグ＆ドロップしても開けます。

> （スクリーンショット予定: docs/user-guide/images/dls/10-data-loaded.png）

---

## 2. 分布タイプと Run の切替

サイドバー「表示」セクションから操作します。

- **分布の種類**: `Number (%)` / `Intensity (%)` / `Volume (%)` / `自己相関 g₂−1` / `温度ランプ T vs d_h` / `濃度シリーズ c vs D` / `サイズ分布逆変換 (CONTIN-like)` を切り替えます。Number / Intensity / Volume / サイズ分布逆変換は粒径（nm）を X 軸に、g₂−1 は遅延時間（μs）を X 軸に、温度ランプは温度（°C）を、濃度シリーズは濃度（mg/mL）を X 軸に取り、軸ラベルとスケールが自動的に切り替わります。
- **Run**: Zetasizer は通常 3 回繰り返し測定を 1 シート内に記録します。ドロップダウンから個別の Run を選択できます。温度ランプ / 濃度シリーズモードでは Run 選択は使われません（各シートを 1 温度点 / 1 濃度点として扱います）。サイズ分布逆変換モードはデフォルトで Run 1 の自己相関関数を使います。

> （スクリーンショット予定: docs/user-guide/images/dls/15-distribution-mode.png）

---

## 3. 測定条件の補完

サイドバー「測定条件」セクション（選択中のシート単位）に、Stokes–Einstein 計算で使うパラメータを入力します。

- **温度 (°C)**, **濃度 (mg/mL)**, **溶媒**, **屈折率**, **粘度 (mPa·s)**, **波長 (nm)**, **散乱角 (°)** の 7 項目です。
- 必須なのは温度・粘度・波長・散乱角の 4 つで、欠けている項目はキュムラント解析カードのステータスメッセージに列挙されます。
- 値はシート単位で記憶され、`.dlsjson` に保存されるので、次回読み込み時に同じ値が復元されます。

> （スクリーンショット予定: docs/user-guide/images/dls/18-measurement-conditions.png）

---

## 4. キュムラント解析

サイドバー「キュムラント解析」セクションは選択中のシートに対して動作します。

- **フィット範囲 (μs)**: 空欄にすると `g₂−1 ≥ 0.1` を保持する範囲が自動選択されます。任意で min / max を直接入力することも可能です。
- **Z-average 径**, **PdI**, **Γ**, **適用範囲**, **R²** が表示されます。Stokes–Einstein 計算に必要な測定条件が揃っていれば Z-average 径として流体力学径が、揃っていなければ Γ から計算可能な値だけが表示され、不足項目はステータスメッセージで案内されます。

理論的には `ln|g₁(τ)| ≈ −Γτ + (μ₂/2)τ² − …` を Siegert 関係 `g₂−1 = β·|g₁|²` 経由で `y = ln(g₂−1)` の 2 次多項式に置き換え、`a₁ = −2Γ`, `a₂ = μ₂` から PdI = μ₂/Γ² を求めています。

> （スクリーンショット予定: docs/user-guide/images/dls/22-cumulant-analysis.png）

---

## 5. 温度ランプ解析

サイドバー「温度ランプ解析」セクションは、読み込んでいるすべてのシートを 1 温度点として扱い、Boltzmann シグモイド `d_h(T) = d_low + (d_high − d_low) / (1 + exp(−(T − T_c) / w))` を当てて転移点 T_c（PNIPAM なら LCST）と転移幅 w を抽出します。

- 各シートの「測定条件」サイドバーで **温度 (°C)** を入力しておく必要があります（粘度・屈折率・波長・散乱角もキュムラント解析用に必須）。温度未入力のシートは自動的に除外されます。
- 「分布の種類」を **「温度ランプ T vs d_h」** に切り替えるとプロット側も T vs d_h の散布図 + Boltzmann fit カーブに変わります。
- 表示される値は **T_c (転移点)**、**転移幅 w**、**低温プラトー d_low**、**高温プラトー d_high**、**R²** の 5 つ。除外されたシートがある場合はステータスメッセージで件数（温度未入力 / キュムラント失敗）が表示されます。
- 4 点未満では fit を試行しません（温度範囲も最低 1 °C のスパンを要求します）。
- d_h が温度上昇で大きくなる PNIPAM 型でも、温度低下で大きくなる UCST 型でも、`w` の符号が自動的に決まります。

> （スクリーンショット予定: docs/user-guide/images/dls/25-temperature-ramp.png）

---

## 6. 濃度シリーズ解析

サイドバー「濃度シリーズ解析」セクションは、読み込んでいるすべてのシートを 1 濃度点として扱い、`D(c) = D₀·(1 + k_D·c)` を線形回帰して無限希釈拡散係数 D₀ と拡散ビリアル係数 k_D を抽出します。サンプル間相互作用の効果を取り除いた「真の流体力学径 d_h(c→0)」も同時に計算されます。

- 各シートの「測定条件」サイドバーで **濃度 (mg/mL)** を入力しておく必要があります（粘度・屈折率・波長・散乱角もキュムラント解析用に必須）。濃度未入力のシートは自動的に除外されます。
- 「分布の種類」を **「濃度シリーズ c vs D」** に切り替えるとプロット側も c vs D の散布図 + 線形 fit カーブに変わります。Y 軸の単位は人が読みやすい μm²/s （= 10⁻¹² m²/s）です。
- 表示される値は **D₀ (c→0)**、**k_D**、**d_h (c→0)**、**R²**、**参照条件 (T / η)** の 5 つ。D₀ と k_D には標準誤差 (1σ) も `±` の形で添えられます。除外されたシートがある場合はステータスメッセージで件数（濃度未入力 / キュムラント失敗）が表示されます。
- 3 点未満では fit を試行しません（濃度範囲も最低 0.001 mg/mL のスパンを要求します）。
- 参照温度・粘度はシート横断で揃っていることが前提です。シート間で値がずれている場合は中央値を採用したうえで「シート間で温度/粘度が異なります」と警告します。
- k_D が負ならサンプル間に引力性の相互作用（凝集の前段階・LCST 近傍など）、正なら斥力性（良溶媒・荷電粒子など）が働いていると読みます。

> （スクリーンショット予定: docs/user-guide/images/dls/27-concentration-series.png）

---

## 7. サイズ分布逆変換 (CONTIN-like)

サイドバー「サイズ分布逆変換」セクションは、選択シートの自己相関関数 `g₂−1(τ)` を Tikhonov 正則化付き NNLS（非負最小二乗法）で連続サイズ分布に逆変換します。キュムラント解析が「全体の平均」を返すのに対し、逆変換はピーク構造そのものを再構成するので、二峰サンプル（コイル + 凝集体、コア + シェルなど）の「もう一方のピーク」を見たいときに使ってください。

数学的にはカーネル `K[i,j] = exp(−Γ_j · τ_i)` で `g₁(τ_i) = √((g₂−1) / β)` を `min ‖K·x − y‖² + α² ‖L·x‖²  s.t. x ≥ 0` で逆ラプラス変換しています。L は二階差分演算子で、滑らかさを強制してサイズ軸上の単一ビンへのアーティファクト集中を防ぎます。サイズ軸は 0.4–10000 nm を log-spaced 60 ビンで切ります。

- 「分布の種類」を **「サイズ分布逆変換 (CONTIN-like)」** に切り替えると、選択シート 1 つ以上に対して逆変換が走り、結果が散布図（log-X 軸）として描画されます。複数シート選択時は重ね描きになります。
- **重み** ドロップダウンで `Intensity (%)` / `Number (%)` / `Volume (%)` を切り替えます。Number は Intensity を `1/d⁶` で、Volume は `1/d³` で再重み付けし、それぞれ 100% に正規化します。多峰サンプルでは Intensity → Number に切り替えると小さい粒子の存在感が大きく増えるはずです。
- **α 自動選択**: 既定の ON では α を log-spaced 16 候補で sweep し、L-curve（残差 vs 滑らかさのトレードオフ）の角を Hansen 2007 の三角形面積法で検出します。OFF にすると **手動 α** TextBox が有効になり、任意の値を指定できます。α が小さすぎると過剰適合（peaky）、大きすぎると過剰平滑（broad）になります。
- 結果として **採用 α**、**R²**（g₁ ドメイン）、**β**（推定された自己相関の τ→0 高さ）、**自由ビン数 / 全ビン数**（NNLS が非ゼロにしたビンの数）を表示します。複数シート選択時はサイドバーの結果は先頭シートのものを示し、ステータスメッセージで件数を案内します。
- 必要なメタデータはキュムラント解析と同じ 4 項目（温度・粘度・屈折率・波長・散乱角）。不足があるとステータスに列挙されます。
- 計算は 1 シートあたり典型 0.2–1 秒。重ね描きで重く感じる場合は α を手動指定すると候補 1 つだけで済むので 16 倍速くなります。

> （スクリーンショット予定: docs/user-guide/images/dls/29-size-distribution-inversion.png）

## 8. グラフ調整

サイドバーの「線スタイル」「軸範囲」「グラフラベル」「グラフ書式」の各セクションから、書式を調整します。

- **線スタイル**: 選択中のデータセットの色・凡例名・線幅・マーカーサイズを設定します。色は名前付きプリセットに加え、Custom 選択時は hex 入力 / HSV パレットが利用できます。
- **軸範囲**: マウスでドラッグ・ホイール操作後、TextBox に表示された値を微調整するのが楽です。空欄に戻して **「自動範囲に戻す」** を押すと自動レンジに戻ります。粒径分布では X 軸が log スケールになります。
- **グラフラベル**: タイトル、X 軸、Y 軸ラベルを直接入力します。タイトル・軸ラベルは太字切替、タイトルは表示／非表示の切替もできます。
- **グラフ書式**: フォント、フォントサイズ、グリッド表示、プロット枠（色・幅）、背景色、凡例位置、アスペクト比（16:9 / 4:3 / 3:2 / 1:1 / 自動）を指定できます。

凡例の位置はドラッグでも変更できます。マウスを離した位置に最も近い 9 つの隅・辺・中央のいずれかに自動でアンカーされます。

書式設定は **「既定保存」** ボタンで `%AppData%\LabPlot.DLS\formatting_config.json` に保存され、次回起動時に復元されます。

> （スクリーンショット予定: docs/user-guide/images/dls/30-formatting.png）

---

## 9. 出力

メインエリア右上の 2 つのボタンから書き出します。

- **「PNG / SVG 保存」**: 分布／自己相関／温度ランプ／濃度シリーズ／サイズ分布逆変換グラフを出力します。PNG は 3600 × 2160 / 300 dpi、SVG はベクターで保存されます。アスペクト比設定が出力サイズに反映されます。
- **「データ出力」**: 分布データ・相関関数・キュムラント解析結果を Excel ブック（`.xlsx`）または CSV で書き出します。

---

## 10. 解析条件を保存・読み込む

サイドバー下部「解析条件」セクションから操作します。

- **「条件を保存」（Ctrl+Shift+S）**: 読み込んでいるデータファイルパス、線スタイル、軸範囲、書式、測定条件、キュムラント解析の設定をまとめて `.dlsjson` に書き出します。
- **「条件を読込」（Ctrl+Shift+O）**: 保存した `.dlsjson` を読み込んで状態を復元します。データファイルの実体は元の場所から再読込されるため、ファイルが移動・削除されているとその項目だけ警告つきでスキップされます。

> （スクリーンショット予定: docs/user-guide/images/dls/50-session.png）

---

## 11. 環境設定（任意）

サイドバー最下部の「環境設定」セクションから、よく使う既定値を保存できます。

- **既定の分布**: Number / Intensity / Volume / 自己相関 / 温度ランプ / 濃度シリーズ / サイズ分布逆変換 のうち、起動時に最初に開く分布タイプ。
- **既定の Run**: 起動時に選択しておく Run のインデックス。
- **既定の出力フォルダ**: グラフ・データ・解析条件の保存ダイアログでこのフォルダが最初に開かれます。

入力後はサイドバー下部の **「既定保存」** を押すと反映されます。

> （スクリーンショット予定: docs/user-guide/images/dls/60-preferences.png）

## 詳細仕様メモ

- Zetasizer の列ヘッダは `<DataType> (<unit>) - <SampleName> [<State>]` という構造を仮定しており、`Size (d.nm)` / `Number (Percent)` / `Intensity (Percent)` / `Volume (Percent)` / `Correlation` / `Time` のキーワードで分類します。
- キュムラント解析は遅延時間 μs を基準にしており、Γ は μs⁻¹、μ₂ は μs⁻² で内部計算した上で、UI 表示・Stokes–Einstein 計算用に SI 単位（s⁻¹, m²/s）へ変換しています。
- Stokes–Einstein 式は `D = kT / (6πηR_h)` を `R_h = kT / (6πηD)` に変形して使い、散乱ベクトル `q = (4πn/λ)·sin(θ/2)` から拡散係数 `D = Γ/q²` を計算しています。屈折率・粘度・波長・散乱角のいずれかが欠けると計算をスキップし、UI に不足項目を表示します。
- セッション JSON は UTF-8（BOM 付き）で書き出され、書式設定の `formatting_config.json` とは別のファイルです。
