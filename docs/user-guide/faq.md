## .NET ランタイムを別途インストールする必要はありますか？

不要です。配布物は self-contained ビルド（必要なランタイムを 1 本にまとめた single-file 実行形式）として作られているので、解凍してダブルクリックするだけで起動します。

---

## Mac で動きますか？

動きます。Apple Silicon（M1 / M2 / M3 系、`osx-arm64`）で動作確認しています。Intel Mac（x86_64）向けの配布物は通常用意されていないので、必要な場合は研究室の管理者に相談してください。

初回起動時に Gatekeeper の警告が出る場合の対処は [インストール（macOS）](./installation.md#インストールmacos) を参照してください。

---

## Linux で動きますか？

動きます。x64 ディストリビューション（Ubuntu 22.04 LTS 等）で動作確認しています。日本語表示が豆腐になる場合は CJK フォント（`fonts-noto-cjk` 等）をインストールしてください。

WSL2 + WSLg（Windows 11 標準）の環境でも GUI が立ち上がるので、Linux 実機が無い場合の動作確認に使えます。

---

## 旧 WPF 版（v1.1.0）と何が違いますか？

機能と操作感はほぼ共通です。主な違いは次の 3 点です。

1. 対応 OS: Avalonia 主流版（v1.2.0）は Windows / macOS / Linux 共通、旧 WPF 版（v1.1.0）は Windows 専用です。
2. 新機能・バグ修正: 主流版にのみ追加されます。旧 WPF 版は v1.1.0 で feature freeze しており、深刻な不具合の修正以外は基本的に入りません。
3. 見た目の細部: スクロールバーの常時表示、フォーカスリングの色、Expander のシェブロンの動きなど、磨き込みが入っているのは主流版です。機能差ではないので操作には影響しません。

新規利用者には主流版（v1.2.0 以降）を推奨します。Windows でしか使わない既存利用者も、特別な事情が無ければ主流版に乗り換えて問題ありません。

## サンプルデータはどこにありますか？

配布物（zip）を解凍したフォルダ直下の `samples/` にあります。GPC・Spectrum・DLS いずれも動作確認用のサンプルが同梱されています（DLS は合成データの `demo.xlsx`）。詳細は [サンプルデータ一覧](./samples.md) を参照してください。

## 出力した PNG の解像度はどれくらいですか？

PNG 出力は 300 dpi、ピクセルサイズで 3600 × 2160 です（アスペクト比設定が「自動」以外の場合はその設定値に従います）。投稿論文の Figure としても十分な解像度を確保しています。

ベクター形式が必要な場合は SVG 出力を選んでください。

## グラフの書式設定はどこに保存されますか？

「既定保存」ボタンを押すと、各モジュールごとに `formatting_config.json` が OS のユーザー領域に書き出されます。Windows 上の保存先は次のとおりです。

| モジュール | 保存先 |
| --- | --- |
| GPC | `%AppData%\GPC_Visualization\formatting_config.json` |
| Spectrum | `%AppData%\Spectrum_Visualization\formatting_config.json` |
| DLS | `%AppData%\LabPlot.DLS\formatting_config.json` |

`%AppData%` は `C:\Users\<ユーザー名>\AppData\Roaming` です。macOS / Linux でも同じ階層構造で、各 OS のユーザー設定ディレクトリ配下に保存されます。

リセットしたい場合はこのファイルを削除すれば、ソース上の出荷時デフォルトに戻ります。

## セッションファイル（.gpcjson / .specjson / .dlsjson）を別 PC や別ユーザーに渡しても大丈夫ですか？

セッションファイルにはデータファイルへの絶対パスが含まれます。受け取った側で同じ場所にデータがあれば再現できますが、パスが異なる場合は読み込み時に「ファイルが見つかりません」という警告が出てその項目だけスキップされます。

ただし、セッションファイルには出力フォルダや GPC の検量線パスといった環境設定（`formatting_config.json` 側で保持しているもの）は含まれない設計になっています。受け取った側の環境設定を上書きしないので、共有しやすい構造になっています。

データファイルとセッションファイルをセットでまとめて渡し、受け取った側で同じディレクトリ構造に展開するのが一番確実です。

---

## ScottPlot のグラフを EPS や PDF で出したいです

LabPlot は PNG（300 dpi）と SVG の 2 種類で出力します。EPS や PDF が必要な場合は、SVG として出力したあとに Inkscape や Adobe Illustrator などで変換してください。SVG はベクター形式なので、変換時に画質劣化はありません。

## バグを報告したいです

GitHub の Issues ページに投稿してください。

- Issues: <https://github.com/unknowns53/LabPlot/issues>

報告に含めると有り難い情報は次のとおりです。

- 発生した日時
- 操作の流れ（どのモジュールで、どのファイルを開いて、どのボタンを押したか）
- 期待した挙動と、実際の挙動の差
- OS とそのバージョン
- LabPlot のバージョン
- `shell-error.log` の中身（[ログの場所](./portal.md#ログの場所) を参照）

詳細なテンプレートは [トラブルシューティング](./troubleshooting.md) の最後のセクションにあります。
